목적과 대상

Carve Usage Report (Personal)은 leetaek이 본인 계정의 새기다 운영 집계를 확인하는 개인용 보고 도구입니다. 일반 방문자를 위한 유료 서비스나 계정 연결 서비스는 제공하지 않습니다. 이 안내 페이지를 방문하는 것만으로 결제·구독 또는 Google 접근 승인이 발생하지 않습니다.

접근 권한과 사용

도구는 운영자가 적법한 조회 권한을 보유한 계정과 앱 데이터만 처리합니다. Google·Apple·GitHub·OpenAI 등 이용하는 서비스의 약관과 API 정책을 준수해야 하며, 다른 사람의 인증 정보를 무단으로 사용하거나 접근 제한을 우회해서는 안 됩니다.

OAuth 승인 및 API 키의 관리 책임은 운영자에게 있습니다. 도구는 광고 설정 변경, 구매·결제·송금 또는 캠페인 실행을 수행하지 않습니다. 데이터 처리 방식은 개인정보처리방침을 따릅니다.

지표의 의미와 한계

광고 수입과 인앱결제 개발자 수익은 각 플랫폼이 제공하는 예상값입니다. 집계 지연, 환불, 환율, 세금·수수료, 보고서 수정과 보존 범위에 따라 값이 달라질 수 있습니다. 실제 정산이나 입금액을 보장하지 않으며, 회계·세무 신고의 확정 자료를 대신하지 않습니다.

조회 실패·행 누락·보고서 생성 대기를 0으로 해석하지 않습니다. 조회 범위와 전체 이력의 포함 여부를 확인한 뒤 지표를 해석해야 합니다.

변경과 중단

플랫폼의 정책·권한·API 변경이나 운영자의 설정에 따라 조회가 중단되거나 도구의 기능이 바뀔 수 있습니다. 지속적인 제공이나 특정 시점의 보고 완료를 보장하지 않습니다. 운영자는 자동 보고 중지와 API 접근 권한 회수를 통해 사용을 중단할 수 있습니다.
