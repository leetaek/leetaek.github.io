앱의 사용 추이와
예상 수입을 한곳에서.

Carve Usage Report (Personal)은 iPad 성경 필사 앱 새기다의 운영자가 본인 계정의 집계 지표를 확인하고, 일일 운영 보고를 작성하는 도구입니다.

운영자 본인이 사용하는 도구입니다.

이 웹사이트는 도구와 데이터 처리 방식을 안내합니다. 일반 방문자를 위한 가입·로그인·계정 연결 기능은 제공하지 않으며, 운영 보고서는 이곳에 공개하지 않습니다.

어떤 정보를 확인하나요?

Google AdMob
새기다의 광고 실적과 예상 광고 수입을 조회합니다.
Google Analytics
활성 사용자, 참여 시간, 필사 이벤트 등 앱 사용 집계를 확인합니다.
App Store Connect
다운로드, 공유에 동의한 표본의 세션 집계, 인앱결제 예상 개발자 수익을 확인합니다.

Google 접근 권한을 요청하는 이유

AdMob 보고서는 운영자의 Google 계정 승인이 필요합니다. 이 도구의 OAuth 연결은 광고 성과와 수익 보고서를 읽는 admob.report 권한만 요청합니다. 이 권한으로 보고서에 필요한 게시자 식별자·시간대·통화도 확인합니다. GA4는 별도로 권한을 받은 읽기용 서비스 계정으로 조회합니다.

광고 설정을 변경하거나 결제·송금·캠페인을 실행하는 기능은 없습니다. 인증 정보는 운영자의 Mac에 보관하고, 필요한 집계값만 운영자의 Codex 채팅에 보고합니다.

예상 수입을 읽는 방법

광고 예상 수입과 인앱결제의 세금·Apple 수수료 차감 예상 수익은 서로 다른 지표입니다. 조회 기간, 통화, 시간대와 데이터 누락을 구분하며, 실제 정산 입금액으로 간주하지 않습니다. 전체 기간을 확인하지 못한 값을 전체 누적 수입으로 표시하지 않습니다.
