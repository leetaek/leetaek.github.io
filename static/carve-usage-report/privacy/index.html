개인정보처리방침

시행일·최종 수정일: 2026년 11월 19일

leetaek이 운영하는 Carve Usage Report (Personal)은 운영자 본인 계정의 앱 운영 집계를 조회하는 개인용 도구입니다. 이 방침은 해당 도구와 이 안내 페이지에 적용되며, 새기다 앱 자체의 개인정보처리방침을 대신하지 않습니다.

접근하는 정보와 목적

  • AdMob: 운영자가 승인한 계정의 광고 성과·예상 수입 보고서와 보고에 필요한 게시자 식별자·시간대·통화에 접근합니다. 실제 보고는 새기다 앱으로 제한합니다.
  • GA4: 읽기용 서비스 계정을 통해 새기다의 활성 사용자·참여 시간·필사 이벤트 집계를 조회합니다.
  • App Store Connect: 읽기용 보고 키를 통해 새기다의 다운로드·동의 표본 세션·인앱결제 예상 개발자 수익 집계를 조회합니다.
  • 인증 정보: 승인된 API를 반복 조회하기 위해 OAuth 갱신 토큰과 API 키를 사용합니다.

이 정보는 운영자의 앱 사용 추이와 예상 수입을 비교하고 일일 운영 보고를 작성하는 데 사용합니다. 방문자의 Google 계정을 연결하거나 방문자로부터 운영 보고 데이터를 받는 기능은 없습니다.

Google 권한과 이용 범위

AdMob OAuth는 보고서 읽기 범위인 https://www.googleapis.com/auth/admob.report만 요청합니다. 광고 설정 변경, 구매·결제 또는 캠페인 실행을 위한 권한은 요청하지 않습니다.

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. Google 사용자 데이터를 판매하거나 광고 타기팅·신용 평가·범용 AI 모델의 개발 또는 학습에 사용하지 않습니다.

보관과 보호

OAuth 토큰·API 키는 운영자의 Mac에서 소스 저장소 밖 사용자 전용 위치에 보관합니다. 보고용 OAuth 토큰은 사용자 전용 파일 권한으로 생성합니다. 인증 정보는 공개 저장소·정책 페이지·일일 보고에 포함하지 않습니다.

원본 보고서는 조회·집계하는 동안 메모리에서 처리하며 수집기가 별도 파일로 보관하지 않습니다. 인증 정보는 연결을 유지하는 동안 보관하며, 연결 해제 시 운영자가 로컬에서 삭제할 수 있습니다. 운영자가 별도로 내보낸 자료는 운영자가 관리합니다.

외부 서비스와 보고 데이터

인증·토큰 갱신·보고 조회를 위해 Google 및 Apple의 공식 API를 이용합니다. 일일 보고 작성에 필요한 집계값은 운영자의 OpenAI Codex 채팅에서 처리·보관됩니다. 인증 정보와 원본 보고서는 보고 프롬프트에 포함하지 않습니다.

Codex에서 처리되는 보고 내용은 운영자가 선택한 계정·워크스페이스의 데이터 설정과 OpenAI 개인정보처리방침 등 해당 서비스의 정책이 적용됩니다. 채팅의 보관·삭제는 해당 서비스에서 별도로 관리합니다. 이 도구는 처리 데이터를 불특정 다수에게 공개하거나 다른 고객에게 제공하지 않습니다.

연결 해제와 삭제

운영자는 Google 계정의 서드 파티 연결 관리에서 도구의 권한을 취소할 수 있습니다. 이후 로컬 인증 파일을 삭제하고 자동 보고를 중지하면 추가 조회가 중단됩니다. Google 권한 취소는 GA4 서비스 계정이나 Apple API 키를 자동으로 해제하지 않으므로, 각 서비스의 접근 권한도 별도로 회수해야 합니다.

이미 작성된 보고의 삭제는 Codex 채팅과 별도로 보관한 자료에서 각각 수행합니다.

안내 웹페이지 방문

이 세 안내 페이지에는 로그인 폼·분석 스크립트·광고·외부 글꼴을 넣지 않습니다. GitHub Pages 호스팅 제공자는 요청을 처리하면서 IP 주소 등 접속 정보를 처리할 수 있으며, GitHub 개인정보처리방침이 적용됩니다. 같은 도메인의 다른 블로그 페이지는 구성이 다를 수 있습니다.
