이 방침은 블로그 「iOS 개발 기록」(https://leetaek.github.io/)에 적용됩니다. 앱 「새기다」의 처리방침은 [따로](/carve/privacy/) 있습니다.

이 블로그에는 회원가입이 없고, 운영자가 방문자에게 개인정보를 직접 받지 않습니다. 다만 아래 외부 서비스가 쿠키 같은 기술로 방문 정보를 처리합니다.

## 1. 호스팅 — GitHub Pages

블로그는 GitHub Pages 로 제공됩니다. 페이지를 열면 GitHub 가 IP 주소 같은 접속 기록을 보안과 서비스 운영 목적으로 처리할 수 있습니다. 자세한 내용은 [GitHub 개인정보처리방침](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)을 참고하세요.

## 2. 방문 통계 — Google Analytics

어떤 글이 읽히는지 보려고 Google Analytics 4 를 씁니다. Google 은 쿠키로 방문한 페이지, 머문 시간, 기기 · 브라우저 종류, 대략적인 위치 같은 정보를 모아 운영자에게 통계로 보여 줍니다. 운영자는 개별 방문자를 식별하는 데 이 정보를 쓰지 않습니다.

수집을 원하지 않으면 브라우저에서 쿠키를 막거나 [Google 애널리틱스 차단 부가기능](https://tools.google.com/dlpage/gaoptout)을 설치하세요.

## 3. 광고 — Google AdSense

이 블로그는 Google AdSense 광고를 게재합니다.

- Google 을 포함한 제3자 공급업체는 쿠키를 사용해, 방문자가 이 블로그나 다른 웹사이트를 방문한 기록을 바탕으로 광고를 게재합니다.
- Google 은 광고 쿠키를 사용해 방문자가 이 블로그나 다른 사이트를 방문한 기록에 따라 Google 과 파트너가 광고를 게재할 수 있게 합니다.
- [Google 광고 설정](https://adssettings.google.com/)에서 맞춤 광고를 끌 수 있습니다. 제3자 공급업체의 맞춤 광고 쿠키는 [www.aboutads.info](https://www.aboutads.info/choices/)에서 끌 수 있습니다.

Google 이 이 정보를 어떻게 쓰는지는 [Google 파트너 사이트 데이터 사용 방식](https://policies.google.com/technologies/partner-sites)에 나와 있습니다.

## 4. 댓글 — giscus(GitHub Discussions)

글 아래 댓글은 [giscus](https://giscus.app/ko)로 받고, 이 블로그 저장소의 GitHub Discussions 에 저장됩니다. 댓글을 쓰려면 GitHub 계정으로 로그인해야 하고, 쓴 댓글과 GitHub 사용자 이름은 공개됩니다. 댓글은 GitHub 에서 직접 고치거나 지울 수 있습니다.

## 5. 쿠키 거부

브라우저 설정에서 쿠키를 막거나 지울 수 있습니다. 쿠키를 막아도 글은 그대로 읽을 수 있습니다.
